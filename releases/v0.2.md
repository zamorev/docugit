## Docugit 0.2 — macOS

Search in notes, a much stronger **Editor** and **Source** experience on native text views, plus Git and AI polish and many small fixes.

### Highlights

- **Find in note** — ⌘F (Edit → Find in Note): search bar, next/previous match, highlight in **Editor**, **Source**, and **Preview** (Preview searches the note text, not the rendered layout).
- **Editor** — AppKit prose editor with Markdown styling, wikilinks, tables, and smoother editing than 0.1.1.
- **Source** — syntax highlighting, **line numbers**, and a dedicated native source editor (replaces the basic SwiftUI source field from early access).
- **Git** — fresher status in the toolbar; **commit local changes** from the Updates section when you are ahead with uncommitted work.
- **AI assistant** — improved editing flows and chat UI; copy assistant messages in one tap.
- **Settings** — typography options; **Reveal in Finder** for the current note.
- **Stability** — bug fixes and performance tweaks across the app.

### Requirements

- macOS 14 (Sonoma) or later
- Git (Xcode Command Line Tools or Homebrew)

### Install

1. Download **Docugit-0.2.dmg** below.
2. Open the disk image and drag **Docugit** to Applications.
3. Replace an older copy in Applications if you already use Docugit.
4. On first launch after update, allow the app if macOS asks (Developer ID build).

### Upgrading from 0.1.1

- **No in-app auto-update** — download this release and drag **Docugit** into Applications again.
- Your vault folder and Git remote are unchanged; settings stay in the app.

### Known limitations

- **Preview + Find** — highlights match the Markdown source text, not the rendered preview.
- **Early access** — feedback welcome via [Issues](https://github.com/zamorev/docugit/issues).
- **iOS** — not in this build.
