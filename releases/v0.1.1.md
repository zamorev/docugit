## Docugit 0.1.1 — Early access (macOS)

First public macOS build for dogfooding. Your notes stay as **plain Markdown files** in a folder you choose; sync is **your Git remote** (GitHub, GitLab, or self-hosted).

### Highlights

- **Vault** — open a folder, browse notes in the sidebar, wikilinks and backlinks, autosave.
- **Editor modes** — Editor (prose), Source (Markdown with highlighting), Preview (GFM rendering).
- **Tabs** — several notes open at once; drag notes in the sidebar or into the editor.
- **Git** — connect or clone a repo, sync with one action, PAT stored in Keychain; basic conflict handling.
- **AI assistant** — bring your own API key; chat and `/edit` suggestions with review before you keep changes.
- **Settings** — English and Russian UI.

### Requirements

- macOS 14 (Sonoma) or later
- Git (Xcode Command Line Tools or Homebrew)

### Install

1. Download **Docugit-0.1.1.dmg** below.
2. Open the disk image and drag **Docugit** to Applications.
3. On first launch, allow the app if macOS asks (Developer ID build).

### Known limitations

- **Early access** — rough edges expected; feedback welcome via [Issues](https://github.com/zamorev/docugit/issues).
- **No in-app auto-update yet** — install new builds from [Releases](https://github.com/zamorev/docugit/releases) manually.
- **iOS** — not in this build.
- **Source view** — uses SwiftUI text editing; advanced source layout features may land in later builds.
